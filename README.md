# ExplanationOptimisation

This repository is centered around a research project I undertook with Dr Bernard Evans at the University of Adelaide.
The aim of this project was to investigate the extent to which explanation quality from an XAI model could be improved through integration with the training of the 
base Neural Network. Due to my proficiency with graph-based machine learning models, we conducted the experiments using GNN's. 
The layout of the repository is such that experiments are located next to similar experiments within specific folders.
